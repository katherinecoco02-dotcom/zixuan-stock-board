# 自选股看板

基于「同花顺金融数据服务」（hithink-finance）的本地自选股看板。
单页界面，**左侧自选股列表 + 右侧 K 线图，点击即切换、不跳页**。

打开：<http://127.0.0.1:8787>

---

## 装给别人用（Windows，三步）

1. 把这个文件夹放到目标机器上任意位置（下载 ZIP 解压、或 `git clone`）
2. **双击 `安装.cmd`**
   （不要直接双击 `install.ps1` —— Windows 默认不允许双击运行 PowerShell 脚本）
3. 按提示粘贴**你自己的**同花顺 API Key，装完桌面就会多出两个图标

安装程序会自动：检查/安装 Node.js → 验证 API Key 能否真正取到数据 →
在桌面创建「自选股看板 开关」快捷方式与「自选股看板」链接 → 问你要不要立刻启动。

装好后日常只需要桌面那**两个图标**：

| 桌面图标 | 作用 |
|---|---|
| **自选股看板 开关** | 切换式开关：服务没在跑 → 启动并自动开浏览器；已在跑 → 停止 |
| **自选股看板** | 看板地址链接 → <http://127.0.0.1:8787> |

> ⚠️ **每个人要用自己的 API Key。** Key 与同花顺账号绑定，不能共用。
> 到 <https://fuyao.aicubes.cn/admin/> 用同花顺账号登录后签发（没有账号要先注册）。
> Key 只保存在本机 `.apikey` 文件里，`.gitignore` 已包含它，不会被提交。

**前置要求**：Windows 10/11 + Node.js 18 以上（安装程序可以帮你装）。
项目**零第三方依赖**，不需要 `npm install`。

---

## 启动（细节）

**推荐：用桌面上的开关**（双击即可，无需命令行）

| 桌面文件 | 作用 |
|---|---|
| `自选股看板 开关.cmd` | **切换式开关**：服务没在跑 → 启动并自动打开浏览器；已在跑 → 停止 |
| `自选股看板.url` | 看板地址链接 → <http://127.0.0.1:8787> |

使用顺序：**先双击「开关」启动服务，再打开「链接」**。服务没启动时直接点链接会显示无法连接。

`开关` 的判定以 **HTTP 健康检查**为准，而不是看端口——本机上实测
`Get-NetTCPConnection` / `netstat` 看不到沙箱进程的监听端口，只看端口会把"正在运行"
误判成"没在运行"，进而重复启动、端口冲突、服务再也关不掉。停止时按
`PID 文件 → 端口 → 命令行匹配` 三路定位进程；PID 文件由脚本启动时写入。

排查问题看 `data/toggle.log`（每次点击的状态判定与结果）和 `data/server.err.log`。

**或者手动启动**

```bash
node server.mjs
```

首次使用需要 API Key：把 Key 写入工作目录的 `.apikey`（一行，无引号），
或设置环境变量 `HITHINK_FINANCE_API_KEY`。
Key 在 <https://fuyao.aicubes.cn/admin/> 用同花顺账号登录后签发。

端口默认 8787，可用 `PORT=9000 node server.mjs` 更换；
`DATA_DIR=<目录>` 可把数据文件（自选股/预警/日志）换到别处——测试用的隔离实例靠这个；
`ALERT_INTERVAL_MS` 可改价格预警的轮询间隔（默认 10000，下限 3000）。

## 使用

- **批量添加**：左上输入框粘贴多个代码或名称，用逗号/空格/换行分隔，例如
  `600519 000001 贵州茅台 京东方A`，回车或点「添加」。
- **切换图表**：点左侧任意一行，右侧立即换成该股 K 线，页面不刷新、列表不重排，
  因此自选股的整体涨跌始终在同一屏内可见。
- **删除**：鼠标悬停某行，点右侧的 `×`。
- **区间 / 复权**：右上工具条切换 3月/6月/1年/2年/5年/10年，以及前复权/不复权/后复权。
- **周期**：日 / 周 / 月 / 季 / 年。
  上游 `interval` **只提供日线**，所以周/月/季/年由服务端用日线**聚合**得到，
  口径与行情软件一致（开=区间首根开、高/低=区间极值、收=区间末根收、量额求和，
  时间戳取区间最后一个交易日）。**分时（分钟）数据上游没有任何来源，做不到。**
- **坐标标注**：右侧刻度带独立底色、数字加大加亮，最新价做成高亮标签；
  顶部显示各条均线的**当前数值**（悬停时跟着变），不再只靠颜色分辨。
  大图显示 **MA5 / MA10 / MA20 / MA30 / MA60** 五条；四宫格是小图且不画均线图例，
  为免五条无标注的线分不清，**只画 MA5/10/20/60**（需要的话可以改）。
- **滚轮缩放（每张图独立）**：鼠标悬在图上滚轮上滚放大、下滚缩小，**以光标所在那根为锚点**
  （缩放时光标下的 K 线不动），**双击画布复位**。缩放只影响当前这张图，不改周期、
  也不影响其它图 —— 所以可以在四宫格里让日线缩到 3 个月，而年线仍看 1 年。
- **十字光标**：鼠标在图上移动可逐根查看 OHLC 与成交量。
- 行情每 15 秒自动刷新一次；`刷新` 按钮可立即刷新。

### 画笔（在 K 线上画线）

工具条最右的 **「✏ 画笔」** 一按即可开关，开启后下面多出一行画笔工具条：

| 功能 | 说明 |
|---|---|
| **直线 / 箭头 / 自由曲线 / 方框** | 按住鼠标拖动即可画，抬起落成 |
| **橡皮擦** | 点中画记即删除（线附近 8px 内算命中） |
| **颜色** | 红 / 黄 / 绿 / 蓝 / 紫 / 白 六色 |
| **粗细** | 细 / 中 / 粗 三档 |
| **撤销** | 删掉最后一条 |
| **一键清除** | 清空当前股票的全部画记 |

**关键设计：画记存的是「日期 + 价格」，不是像素坐标。** 所以缩放、换周期、换复权、
改窗口大小之后，画的东西**仍贴在原来那根 K 线和那个价位上**，不会漂。
这条有测试锁着：`chart-test` 会断言换窗口后数据坐标不变、而屏幕位置随之改变。

**两个必须知道的限制**：

- **不做持久化**：画记只存在当前页面的内存里，**刷新页面就清空**；不写服务端、不占磁盘。
  按股票分别暂存，所以在自选股之间来回切换不会串。
- **开启画笔时滚轮缩放与双击复位会暂时失效**（免得画到一半图自己动了）。
  要缩放或换区间，先关掉画笔。

画笔目前只在**单图视图**有；四宫格每格太小，没做。

### 分时（周期选「分时」）

> ⚠️ **分时数据不是上游给的，是本服务自己采样攒出来的。** 这一点必须先清楚。

上游**没有任何 A 股分钟数据**（下面是实测，不是照文档推测）：

| 尝试 | 结果 |
|---|---|
| `high-frequency/intraday`（单日高频分时） | `code=2004` 该数据为同花顺 AI 客户端专用 |
| `high-frequency/historical&interval=1m` | `code=2004` 同上 |
| `prices/historical&interval=1m` | `code=1002` Invalid parameter format: interval |
| 本地是否顺手存过 | 没有：轮询只保留最新一条报价 |

而且**即便那些接口开放也没用**：它们返回的是 `hf_direction`（高频动向）与
`hf_participation`（高频参与度）两个**指标**，**不含价格**，画不出分时图。

**本服务的做法**：交易时段内每 **30 秒**取一次自选股快照，把价格与"当日累计成交量/成交额"
按时间记录，按天写成 `data/intraday/YYYY-MM-DD.jsonl`。画出来的图与行情软件口径一致：

- **价格线** + **均价线**（VWAP = 累计成交额 ÷ 累计成交量，与行情软件黄线同算法）+ **成交量柱**
- 横轴固定铺满 `09:30–11:30 / 13:00–15:00`，**中午休市不占宽度**（图形可跨股票、跨日期直接对比）
- 纵轴按**昨收的百分比**对称展开、0% 居中，右轴同时标百分比与对应价格

**必须知道的限制**：

- **不能回看采集之前的行情**：开盘前就开着服务 → 当天完整分时；下午两点才开 → 只有后半段。
- **没有历史某天的分时**，除非那天已被采集过。已录日期用工具栏的日期选择器回放。
- 只采**自选股**；从复盘/筛选里临时看的股票没有分时。
- 采样间隔默认 30 秒（一天约 480 点），可用 `INTRADAY_INTERVAL_MS` 调整（下限 3000ms）。
- **占空间很小**：历史天会在启动时/跨天时自动 **gzip**（实测 **8.5 倍**，一把 12 只 × 480 点的
  样本从 231 KB 压到 27 KB），只有"今天"的文件保持明文以便继续追加。按 242 个交易日算：

  | 自选股 | 压缩后占用 |
  |---|---|
  | 12 只 | 约 **6.5 MB/年** |
  | 50 只 | 约 **27 MB/年** |
  | 100 只 | 约 **54 MB/年** |

- **可以随时关掉采集**：工具栏分时那一行有「采集」勾选框，关掉后不再采样，
  **已有记录仍可回放**；旁边直接显示「N 天 · 占用多少」。
- 四宫格每格的周期下拉里也有「分时」，可以和日线/周线并排看。

### 四宫格（页签「四宫格」）

**同一只股票的多个周期同屏**，一眼看清大周期与小周期的关系：

- 左侧仍是自选股列表，右侧是**上下排列**的多个面板。
- **默认只展开 日线 + 周线**（各占一半高度，看上去就是上下两张图）；
  **月线与年线默认收成细条** —— 日常用不到，需要时点面板右侧的 `▸` 展开、`▾` 收起。
  至少保留一张展开，不会全收光。
- 每格左上角有**自己的周期选择器**（日/周/月/季/年），可自由组合。
- **点左侧任意自选股，所有格一起切换到该股票**，不需要逐格设置。
- 区间（3月~10年）与复权是全局的，改一次所有格一起重载。
- **每格可独立滚轮缩放、双击复位**：日线太密时直接把那一格缩到 3 个月即可，
  其它格不受影响。表头显示当前可见根数（缩放后变黄）。
- 每格右侧显示该股实时价格与涨跌；悬停时价格跟随显示那一根的收盘与涨跌。
- 切换一只股票会发 4 次请求（同一标的、不同周期），结果走 6 小时磁盘缓存，来回切换很快。
- 服务端会多取约 40% 的历史，给"滚轮缩小"留空间（日线 1 年窗口实际可取到约 400 根）。

四宫格与单图共用同一个 `public/chart.js` 里的 `KlineChart` 组件（compact 模式字号与刻度更少，
且不显示 MA30 与均线图例）。

### 盘面复盘（页签「盘面复盘」）

- **情绪概览**：涨停 / 跌停 / 炸板 / 连板 家数。
- **连板天梯**：2板 ~ 7板+ 各档个股。
- **涨停池**：名称、连板数、封单金额、涨停时间（最多 40 行）。
- **跌停池 / 炸板池**：跌幅、换手、开板次数、首次跌停时间。
- **热股榜 / 飙升榜**：Top30，含热度与排名变动。
- **龙虎榜**：可切 `全部 / 机构 / 游资` 三档，显示涨跌幅、净买额、机构或游资净买、
  关联概念；`change` 与 `net_rate` 上游是小数形式，已在界面上换算成百分比。
- **指定日期复盘**：左下日期选择器可回看近一年内任一交易日；非交易日会被明确拒绝
  并提示，不会静默换成别的日期。
- **任意面板里点股票名 → 右侧图表立刻切到该股**。如果它不在自选股里，标题旁会出现
  `加入自选` 按钮。复盘和自选股共用同一个图表面板，因此切换视图不会丢掉当前查看的股票。

> ⚠️ 一个实测确认的坑：涨停池等接口**省略 `date_ms` 时会回退到"服务端当前自然日"**，
> 周末或盘前调用返回**空数组**（不是最近交易日的数据）。所以本服务一律先从交易日历
> 解析出交易日再显式传入。若最新交易日三个池子全空，会自动回退到前一交易日并在状态栏
> 标注实际使用的日期。

### 选股筛选（页签「选股筛选」）

在全市场约 5571 只 A 股上按条件筛选。条件按**取数代价分成四类，各自可折叠**（点分类标题展开/收起）：

**① 行情**（快照直出，零额外请求）

| 条件 | 说明 |
|---|---|
| 价格 / 涨跌幅 / 成交额(亿) / 排除 ST | 基础区间 |
| **振幅 %** | (最高 − 最低) / 昨收 |
| **跳空 %** | (开盘 − 昨收) / 昨收，正=高开 |
| **收盘强度 %** | (收 − 最低) / (最高 − 最低)，100 = 收在当日最高 |
| **阴阳线** | 收阳（收 ≥ 开）/ 收阴 |

**② 估值**（按成交额前 200 只，上游每次限 100 只）
PE(TTM) 区间、PB 区间。

**③ 均线**（需逐只取 K 线，只扫成交额前 N 只）

- **均线参照** MA5/10/20/30/60 ＋ **偏离区间**（%）。偏离为正 = 价格在均线**上方**。
- **均线排列**：多头（MA5>10>20>30>60）/ 空头（反之）。
- **金叉 / 死叉**：近 N 日内 MA5 与 MA10 的交叉（N 可设，默认 5）。
- 三个一键预设：`低于MA60 20%以上`、`不低于MA60`、`MA5 金叉`。

**④ 资金与情绪**（每个条件最多 1 次全市场请求，有 60 秒内存缓存）

| 条件 | 数据来源 |
|---|---|
| 仅今日涨停 | 涨停池 |
| 连板数 ≥ N | 涨停池的 `continue_day_cnt` |
| 仅今日炸板 / 仅今日跌停 | 炸板池 / 跌停池 |
| 龙虎榜：仅上榜 / 机构净买>0 / 游资净买>0 | 龙虎榜（**按档位取对应榜单**） |
| 热榜前 N | 同花顺热股榜 Top30 |
| 异动标签（涨停/跌停/急涨/急跌/快速拉升/快速回落） | 个股异动榜 |

命中的股票会带上**标签胶囊**（如 `2连板`、`龙虎榜`、`热榜#7`、`金叉2日`），一眼看出为什么被筛出来。

#### 流水线与覆盖范围

```
全市场行情粗筛 → 资金与情绪过滤（1~3 次全市场请求）→ 均线扫描（前 N 只）→ 估值（前 200 只）
```

**每一步的中间数量都如实报告**，状态栏会显示各池子的大小与各阶段剩余数量。
均线条件触达上限时会明确写「均线扫描只覆盖成交额前 N 只（粗筛后共 M 只）」，
不会让你以为筛的是全市场。日线不足 60 根的新股/长期停牌会被跳过并单独计数，不给假的均线值。

**耗时**（实测）：均线扫 150 只约 **4 秒**（缓存命中）；全冷缓存下受 100ms 节流限制约 15 秒。
纯行情/情绪/估值筛选约 1~2 秒。扫描期间状态栏有实时计时，界面不会像卡死。

⚠️ **异动标签只在交易当日有数据**：上游该接口只提供"当日"数据且**没有日期参数**
（涨停池有 `date_ms` 可回退到上一交易日，异动没有），所以非交易日、盘前调用必然为空。
界面会明确提示这一点，而不是让你以为筛选器坏了。

结果表在启用均线条件后会多两列：**MA{N}偏离**（正红负绿）与**排列**（多头/空头/—）。

#### 还能加哪些维度

| 档次 | 状态 |
|---|---|
| **零额外请求** | ✅ 价格/涨跌幅/成交额/振幅/跳空/收盘强度/阴阳线/排除ST；待加：连续上涨天数、N 日新高新低（需历史，实为昂贵档） |
| **少量请求** | ✅ 均线偏离/排列/金叉死叉、涨停/连板、炸板/跌停、龙虎榜、热榜、异动标签 |
| **昂贵**（每只 1 次） | 待加：财务指标 ROE、毛利率、资产负债率、营收/净利同比、连续增长年数 |
| **不可用** | 主力资金（上游标注 AI 客户端专用，`code=2004`）；分时/tick、Level-2、北向资金、宏观数据 |

### 策略回测（页签「策略回测」）

**双均线策略**：金叉买入、死叉卖出，参数可调（快线/慢线/区间/初始资金/手续费率）。
默认回测当前自选股池，也可在「标的」里填自己的代码。

- **避免未来函数**：第 i 根出现信号，用**第 i+1 根的开盘价**成交，不是当根收盘价。
- 满仓进出，买卖双边各计一次手续费。
- **均线预热**：额外多取一段历史只用于算均线，窗口外不产生任何交易。
- 指标：总收益、年化、最大回撤、交易次数、胜率，以及**同期"买入持有"收益**作对照。
- 点结果里的股票名，右侧 K 线会**标出每一笔买卖点**（▲买入 / ▼卖出）。

> 一个值得注意的实测结果：在自选股池上，MA5/20 多数标的**跑不赢买入持有**
> （例如宁德时代策略 +21.8% vs 持有 +90.2%）。把"持有"这一列摆出来就是为了让这件事
> 一眼可见，而不是只报一个好看的策略收益。

自选股保存在 `data/watchlist.json`，重启后保留。

### 价格预警（页签「价格预警」）

给一只股票设一个价位，到了就提醒你（**判定在服务端做**，不是靠页面盯着）：

- **两种条件**：`跌到（≤ 目标价）`、`涨到（≥ 目标价）`，可加备注（如「支撑位」）。
- 服务端每 10 秒取一次快照，`last_price` 越过目标价即触发 —— **浏览器关着也照样监控**，
  触发会写进 `data/alert.log`；下次打开页面时，没弹过的提示会补弹。
- 提醒方式：页面右上角**弹窗**（点一下直接跳到该股 K 线）+ **一段铃声**
  （WebAudio 现场合成，不依赖音频文件）。
- **铃声**：三音上行的「叮-咚-叮」（A5 880 → C#6 1109 → E6 1319 Hz，每音带 ×2、×2.76 泛音），
  **连响三遍**、约 **3.9 秒**（每遍之间留 0.7 秒空白）。嫌吵就**在页面任意位置点一下**立刻静音。
  参数都在 `public/ring.js` 顶部（音高、遍数、留白），改完刷新页面即可生效；
  「试听铃」按钮可以先听一次。
- 列表每行显示：条件、现价、**距离目标还差多少（含百分比）**、状态（监控中 / 已触发 / 已停用）。
- 「**立即检查一次**」：不等下一个轮询周期，非交易时段也判定，并如实报出当前价差 ——
  设置完当场就能确认"现在离目标多远"。
- **只在交易时段判定**（工作日 09:15–11:30 / 13:00–15:00，且用交易日历排除节假日）。
  原因很实在：非交易时段拿到的是收盘价，拿它比对会让"设置完立刻误报"，
  所以盘后只刷新现价、不判定。
- **触发一次即标记「已触发」**，不重复提醒；想继续盯点「复位」。
- 目标价**当下就已满足**时（比如现价已经跌破你设的价），服务端会立刻触发一次
  并明确警告「价位可能写反了」，不会闷声记一笔了事。

> 实测基线（`scripts/alert-test.mjs`，33 项）：新增/触发/回执/复位/停用启用/删除、
> 参数校验（非法方向、非法价格、空标的、未知操作、不存在的 id）全部通过；
> 「自动轮询触发」这条路径在该脚本跑在交易日时会真实等待一个 10 秒周期确认触发，
> 非交易日则确认**不误报**。周末用 `ALERT_FORCE_SESSION=1` 起一个隔离实例，
> 两条路径都实测过。

## 名称输入的处理规则

按名称添加时按以下顺序匹配，尽量不给你猜错的答案：

1. 精确匹配（含全角/半角归一化 —— 上游把「京东方Ａ」存成全角 Ａ）
2. 去掉 `XD`/`XR`/`DR` 前缀后再精确匹配（除权除息日上游会临时改名）
3. 唯一子串匹配
4. 前缀截断匹配（除息日上游会把名称截断，如「万华化学」→「XD万华化」）；
   仅在候选唯一且长度足够时采用，否则报错而不是乱猜

若名称有多个候选，会**如实告知替你选了哪只以及备选项**，请核对后再决定是否保留。
要保证精确，直接用 6 位代码（自动补 `.SH`/`.SZ`/`.BJ`）。

## 本地接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/watchlist` | 自选股 + 名称 + 实时行情（一次批量请求） |

| GET | `/api/screener?minPrice=&maxPe=&excludeSt=1&…` | 全市场选股筛选（成交额单位为亿） |
| GET | `/api/backtest?fast=&slow=&days=&capital=&fee=&thscodes=` | 双均线回测，`thscodes` 留空则跑自选股池 |
| GET | `/api/alerts` | 预警列表 + 未确认的触发事件 + 监控状态（**不打上游**，所以前端可以 5 秒轮一次） |

> `ring-test.mjs` 用 AudioContext 桩断言铃声结构，而不是"听一遍觉得还行"：
> 默认确实排了 **3 遍 × 3 音 × 3 泛音 = 27 个振荡器**，三遍起点等距（0 / 1.54 / 3.08 秒），
> 每遍内部三个音落在 0 / 0.20 / 0.40 秒，起音时刻是 `currentTime + 0.03` 的绝对时间，
> `stop()` 会把主增益淡出并停掉全部振荡器，连点两次不会两段铃声叠在一起。
> **"连响三遍"这件事因此是可回归验证的**——以后改音色不会悄悄把遍数改掉。

### 修过的一个测试自身的问题（不是为了让它变绿而改口径）

`e2e-test.mjs` 里"买入持有收益与 K 线接口交叉验证"这条，原先直接拿
`/api/kline` 返回的 `items[0]` 手算，但该数组**前面还有一段均线预热 bar**
（比显示窗口多取约 40% + 60 根），于是它算的是 2023-08 起的更长窗口，
而回测算的是 730 天窗口 —— 两边对不上（-22.62% vs +3.85%）。
实测把预热段按 `displayStartMs` 裁掉后，手算结果与回测**完全一致（3.85%）**，
说明出错的是这条测试的取样口径，回测引擎本身没问题。已按 `displayStartMs` 修正。

## 已知限制

- **没有分时（分钟）数据**：上游 `interval` 只接受 `1d`，日线以下的周期无从获取，因此不做。
- K 线只支持日线（上游 `interval` 当前仅接受 `1d`），没有分钟 K 与 tick。
- 历史 K 线每次只能查一只，没有批量接口（四宫格因此是 4 次请求）。
- 周/月/季/年为**本地聚合**，与行情软件的划分口径可能略有差异（周线以周一为起点、
  月/季/年按自然日历），且时间戳取区间最后交易日，所以「1 年 + 年线」会显示 2 根。
- 行情快照不返回中文名，名称由本地代码表（5571 只 A 股）映射。
- 「主力资金」接口上游标注为同花顺 AI 客户端专用，外部调用返回 `code=2004`。
- 上游业务错误一律返回 HTTP 200 + 信封内 `code`，**不能只判断 HTTP 状态码**。
- 复盘面板每次加载会打 6 次上游请求（天梯/热榜/飙升榜与日期无关，但每次仍会取）。
- **未测到的分支**：复盘"最新交易日三个池子全空 → 自动回退前一交易日"这条路径，
  需要上游在交易日返回空数据才能触发，目前无法按需构造；代码已加保护，但**没有实测覆盖**。
- **筛选取值上限**：估值筛选只覆盖成交额前 200 只（上游估值接口每次限 100 只），
  更靠后的候选不参与估值过滤；界面会明确提示。
- **回测策略单一**：目前只有双均线一种策略，没有参数寻优、没有止盈止损、没有仓位管理。
- **回测标的规模**：逐只拉历史 K 线，适合自选股池量级（上限 30 只）。
  全市场回测需要走 `market-dumps` 的 Parquet 全市场日 K，而项目目前零依赖、
  没有 Parquet 解析能力，因此未实现。
- **界面渲染未经我本人目视确认**：数据层与接口层有 22 项自动化测试覆盖，但
  图表的视觉效果（布局、配色、表格在侧栏里是否拥挤）需要你自己打开看一眼 ——
  这次新增的**价格预警界面（列表、距离列、右上角弹窗）同样没有目视确认过**，
  首次使用时请顺手点一下「试听铃」——正常情况下应当**连响三遍**。

### 价格预警的限制（别把它当成"到价瞬间必响"）

- **粒度是 10 秒，不是 tick**：上游只有快照行情，预警轮询虽然用 `ttlMs=0` 绕开了
  10 秒磁盘缓存，但数据源本身就是秒级快照 —— 价格可能已经穿过你的目标价又回来，
  预警仍会（在下一次轮询时）报出，但**不会在触及的那一瞬间响**。
- **只在交易时段判定**：周末 / 盘前 / 午休 / 收盘后都不判定，只用「立即检查一次」手动看价差。
- **弹窗与提示音依赖页面开着**：服务端照常触发并写 `data/alert.log`，但"弹窗 + 响铃"
  发生在浏览器里。**没有做系统级桌面通知**（Windows Toast），关掉浏览器就只能事后补看。
- **铃声要先被浏览器解锁**：音频需要一次用户手势（在页面上点一下）才能播放，
  标签页静音或系统静音同样听不到 —— 用「试听铃」当场确认。
  铃声响三遍约 **3.9 秒**，中途**点页面任意位置即可静音**（没有单独的"停止"按钮）。
- **只做单向、一次性触发**：没有"回落到某价再提醒"的双向监控，也不做重复提醒；
  触发后要点「复位」才会重新生效。
- **`ALERT_FORCE_SESSION=1` 是测试钩子**：强制把时段判定成"交易中"，
  用来在周末验证"自动轮询触发"这条路径。**正常运行不要设置它**，
  否则非交易时段会拿收盘价误报。
